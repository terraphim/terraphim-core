# Terraphim Rolegraph Core

Portable knowledge-graph indexing and symbolic embeddings: TF-IDF trigger indexing and similarity over authored concept relationships. This crate has no network or asynchronous runtime dependency.

```toml
[dependencies]
terraphim_rolegraph_core = "0.1.1"
```

The `kg-integration` types preserve authored concepts and their synonyms. Source and tests: [terraphim-core](https://github.com/terraphim/terraphim-core).
